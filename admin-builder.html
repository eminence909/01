      เมื่อมีคนทำผ่านเกณฑ์ ระบบจะส่ง ประเภท คำนำหน้า ชื่อ นามสกุล หัวข้อ คะแนน และเวลา ไปเก็บใน Google Sheet ของคุณ ตั้งค่าครั้งเดียว

      วิธีตั้งค่า (ทำครั้งเดียว)
      1. เปิด sheets.google.com สร้างตารางใหม่ ตั้งชื่อเช่น "รายชื่อผู้ผ่าน"
      2. เมนู ส่วนขยาย (Extensions) เลือก Apps Script
      3. ลบโค้ดเดิม วางโค้ดด้านล่าง กดบันทึก
      4. กด ติดตั้ง (Deploy) เลือก การติดตั้งใหม่ (New deployment) ชนิด เว็บแอป (Web app) ตั้ง Execute as: Me และ Who has access: Anyone แล้วกด Deploy (ครั้งแรกให้กดอนุญาตสิทธิ์)
      5. คัดลอก Web app URL (ลงท้ายด้วย /exec) มาวางในช่องด้านล่าง
      6. กดส่งทดสอบ ดูว่ามีแถวใหม่ใน Sheet แล้วกดสร้างไฟล์ topics.json และเผยแพร่
      function doPost(e) {
  var lock = LockService.getScriptLock();
  lock.waitLock(10000);
  try {
    var d = JSON.parse(e.postData.contents);
    var s = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
    if (s.getLastRow() === 0) s.appendRow(["เวลา","รหัสหัวข้อ","กิจกรรม","ประเภท","คำนำหน้า","ชื่อ","นามสกุล","คะแนน","เต็ม","เปอร์เซ็นต์"]);
    var c = function(v){ return String(v == null ? "" : v).slice(0, 120).replace(/^[=+@-]/, "'$&"); };
    s.appendRow([new Date(), c(d.topic), c(d.title), c(d.category), c(d.prefix), c(d.first), c(d.last), Number(d.score)||0, Number(d.total)||0, Number(d.percent)||0]);
  } catch (err) {} finally { lock.releaseLock(); }
  return ContentService.createTextOutput("ok");
}

      ดาวน์โหลดไฟล์เดียวเก็บรายการกิจกรรม ธีม ข้อสอบ+เฉลยทุกหัวข้อ (รูปเกียรติบัตรไม่รวมในไฟล์ เพราะใหญ่ รูปยังอยู่ใน GitHub) ถ้าข้อมูลพัง เลือกไฟล์สำรองเพื่อกู้คืนขึ้น GitHub

      เชื่อมต่อ GitHub (เพื่อเผยแพร่ด้วยปุ่มเดียว)

      ไม่บังคับ ถ้าไม่เชื่อมต่อ ยังใช้วิธีดาวน์โหลดแล้วอัปโหลดเองได้เหมือนเดิม

      1. เปิด github.com → รูปโปรไฟล์ → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
      2. ตั้งชื่อ เลือกวันหมดอายุ (แนะนำ 90 วัน) ที่ Repository access เลือก Only select repositories แล้วเลือก repo ของเว็บนี้
      3. ที่ Permissions → Repository permissions ตั้ง Contents เป็น Read and write แล้วกด Generate token
      4. คัดลอก token (ขึ้นต้น github_pat_) มาวางด้านล่าง แล้วกดบันทึก

      token เก็บไว้ในเบราว์เซอร์ของเครื่องนี้เท่านั้น ไม่ถูกส่งไปที่ไหนนอกจาก GitHub และมีสิทธิ์เฉพาะ repo ที่เลือก ถ้าเครื่องหาย ให้ลบ token ที่หน้า GitHub ทันที
